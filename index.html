How It Works

Secure Encryption

Files are encrypted using AES-256-GCM, providing military-grade security for your sensitive data.

No Server Upload

All processing happens in your browser. Your files never leave your device, ensuring complete privacy.

Password Protected

Without the correct password, encrypted files remain completely inaccessible, protecting your data from unauthorized access.

Security Information

Encryption Details:

  • Uses WebCrypto API with multiple algorithms:
    • AES-GCM - Authenticated 256-bit encryption (Recommended)
    • AES-CBC - Standard 256-bit block cipher
    • RSA-OAEP - Asymmetric public-key encryption
  • 256-bit encryption key derived from password
  • Each file has unique random salt and initialization vector
  • Includes authentication tag to detect tampering

Note: If you forget your password, there is NO way to recover your files. Choose a strong password and remember it.

Help & Instructions

Encrypting Files:

  1. Click "Select Files to Encrypt"
  2. Enter a strong password (12+ characters recommended)
  3. Click "Encrypt Files"
  4. Save the encrypted files (.enc extension will be added)

Decrypting Files:

  1. Click "Select Encrypted File"
  2. Enter the correct password used for encryption
  3. Click "Decrypt File"
  4. Save the decrypted file (original filename will be restored)
